# 巨歩 KYOHO
## 日本は、思ったより大きい。

巨大化・縮小しながら走り、山を踏み切り、風に乗るブラウザゲームのプロトタイプです。
バージョン 0.2.0 / 2026-09-07

公開中：<https://kyoho.mocchalera.app/>（[ゲームをプレイ](https://kyoho.mocchalera.app/play/)）　[ソースコード（GitHub）](https://github.com/mocchalera/kyoho-game)

## 最初に — この版で確認できていること

**通信不要の「架空の練習島」は、実際のブラウザで起動・操作・ゲーム進行を検証済みです。日本モードの実際の標高タイル取得・全国の地形表示は、この制作環境の通信制約により未検証です。**

日本モードには国土地理院の PNG 標高タイルの取得、復号、球面上へのメッシュ化、サイズに応じた詳細度の変更を実装しています。テスト用の人工 PNG を与え、読み込みから表示までの処理は検証しました。しかし、それは実際の日本の地形での検証ではありません。この配布物に日本全国の標高データは同梱していません。

架空の地形を日本の地形に見せかけるフォールバックはありません。通信に失敗した場合は説明を表示し、明示的に「練習島」へ移ります。すべての同梱スクリーンショットも練習島です。

## 遊び方

PC では `index.html`（単体配布版は `kyoho.html`）を WebGL 対応ブラウザで開いてください。まず **「練習島で遊ぶ」** を選ぶと、外部通信なしで開始します。OS のファイルプレビューでは JavaScript が動かないことがあります。

ローカルファイルの実行に制限がある場合は、このフォルダで次を実行してください。追加パッケージは不要です。

```sh
python run_local.py --open
```

スマートフォン向けにはタッチ操作を実装しています。iPhone の添付ファイルプレビューを実行環境としては扱っていません。公開版は HTTPS の静的サイトとして配信し、Safari 等で開く構成です。iPhone / Android 実機の検証は未実施です。

タイトル画面と「設定」で、巨人 / 巨大イカを選べます。巨大イカは10本の腕・触腕を動かして歩き、空中では腕を広げて滑空します。どちらも4段階の巨大化に対応し、選択はブラウザに保存されます。移動性能とチャレンジのルールは共通です。

### 操作

| 動作 | PC | タッチ |
|---|---|---|
| 移動 | W A S D / 矢印 | 左スティック |
| 視点 | J / L で左右、I / K で上下（長押し） / 画面をドラッグ | 右側の空いている画面をドラッグ |
| ジャンプ | Space | 「跳ぶ」 |
| 滑空 | 空中で Space 長押し | 空中で「跳ぶ」長押し |
| ダッシュ | Shift | 「ダッシュ」長押し |
| サイズ変更 | 1–4 / E | 下部の身長ボタン |
| 自動走行 | R / ボタン | ボタン |
| 地図 | M | 地図アイコン |
| 写真 | P | カメラアイコン |
| 一時停止・設定 | Esc | メニューアイコン |

身長は 180 m / 600 m / 3 km / 12 km の4段階です。最小でも巨人で、1.8mの人間視点はありません。

自由探索では遠くの光を目指すことも、無視して走ることもできます。90秒チャレンジでは、8つの光を順に回収します。小さな光は 600m 以下で通ります。メニューや地形取得待ちではタイマーが止まります。順位はオンライン共有されず、自己ベストを端末側に記録する設計です。

写真機能は画面の UI を除き、作品名、身長、モード、実地形の場合は出典を付けた PNG を生成します。

## 日本モード

北アルプスを初期地点とし、富士山、南アルプス、八ヶ岳、大雪山、日高、利尻、岩手、鳥海、尾瀬、高尾・奥多摩、紀伊、大山、石鎚、阿蘇、霧島、屋久島、やんばるの計18地点への入口を用意しています。これらはゲームの開始地点で、山頂座標・登山口を厳密に示すものではありません。18の独立したマップではなく、現在地の周りを順次取得する構成です。

- 入力：国土地理院・地理院タイルの `dem_png/{z}/{x}/{y}.png`。
- 画像は 256×256、24ビット値から標高を復号します。
- 無効値と取得失敗を区別します。取得失敗箇所では移動を待機します。データ内で無効とされた箇所は地形を描かず、海面と欠測表示になります。内陸の欠測が海面に見える制約があります。
- 球半径約6371 kmの近似地球に、水平距離と標高を同じ km 単位で配置します。意図的な標高倍率はありません。ただし測量用の厳密な楕円体処理ではありません。
- 身長に応じて z12 / z11 / z9 / z7 を切り替え、1タイル64分割のメッシュへ再標本化します。**10m標高データを参照する形式でも、描画解像度が常に10mになるわけではありません。** 緯度とズームに依存する概算描画間隔を HUD に表示します。
- 7×7タイルを要求し、最大3件を並列取得。可能な環境では PNG を IndexedDB にキャッシュします。
- 入力式の住所・地名検索、道路、実際の建物・樹木・衛星写真・植生・積雪の再現はありません。山名表示と模式的な街・回復についてはv0.2.0の説明を参照してください。地表の色、雪、雲、空、主人公、リングは演出です。
- 湖面、沿岸の欠測、タイル境界、詳細度の切り替えには追加の実データ検証・描画改善が必要です。
- 複数のプレイヤーが競争するサーバーや全国ランキングはありません。

登山・トレランのルート案内、避難、安全判断には使用しないでください。

## 保存とプライバシー

移動記録、自己ベスト、設定、日本モードの再開位置をブラウザの localStorage に保存する実装です。保存できない環境では画面にその旨を表示します。記録の JSON 書き出し・読み込みもあります。インポートで復元するのは距離と自己ベストです。タイル用 IndexedDB と実ブラウザでのセッションをまたぐ保存は、この制作環境では検証できていません。

ログイン・解析 SDK・広告・GPS 位置取得はありません。日本モードでは地理院タイルの配信元に HTTPS リクエストを送ります。端末の現在地は使わず、ゲーム内の位置を使います。

## パフォーマンス

WebGL 1 / 素の JavaScript / HTML / CSS。外部 JavaScript ライブラリ、CDN、フォント、APIキーは不要です。空・地形・キャラクターを描画し、効果音を Web Audio で合成します。負荷に応じた描画解像度の調整と「軽量」設定があります。制作環境のソフトウェア GPU では低フレームレートの場面があり、スマートフォン実機での快適性は保証していません。長時間・全国移動時のメモリ、タイル待機、キャッシュ挙動は今後の検証項目です。

## ファイル

- `index.html`：単体で配布できるゲーム。
- `src/`：分割ソース。
- `build.py`：分割ソースから `index.html` を再生成。
- `run_local.py`：PC向けローカルサーバー。
- `DESIGN.md`：企画の核と次に磨くべき点。
- `TEST_REPORT.md` / `tests/*.json`：実施した43項目と未検証範囲。
- `SOURCES.md`：データ出典・参照した公式仕様。

## 公開に向けて

静的配信の対象は `index.html` のみでも動く構成です。配信先を HTTPS にし、外部 PNG への fetch、Blob画像、インライン JavaScript、WebGL が許可されることを確認してください。厳格な Content Security Policy を使うサイトでは、それに合うようスクリプトの外部化等が必要です。

公開前の最優先事項は、実際の地理院タイルで複数地域の形状を照合し、iPhone Safari・Android Chrome・PCで通信、操作、描画速度、写真保存を確認することです。その検証を経るまでは「全国を完成済みの高精細マップとして遊べる製品」ではなく、**実地形ストリーミング実装を含む操作・ゲーム性の試作版**として扱ってください。

## v0.2.0 — 山名と街の休息地（2026-09-07）

日本モードに国土地理院の山岳データ（1059地点）と24市町村の代表点を追加しました。近くの山・街の名前と距離を画面とミニマップに表示します。画面内の重なりを抑え、地形に隠れるラベルは抑制します。「設定 → 山と街の名前」で切替できます。

街は固定サイズの模式的な建物群と緑の光で表現しています。実際の建物配置ではありません。街の代表点から900m以内で、600m以下に縮み、地面に降りて立ち止まると風のエネルギーが回復します。空中・移動中・巨大なまま・メニュー中・地形取得待機中は街の回復が働きません。地図の「街へ向かう」から24の休息地へ移動できます。

データの出典・原応答・再生成スクリプトは SOURCES.md / data/ / scripts/build-landmarks.py。ゲームへの組み込みは build.py。元のv0.1ファイルは backups/pre-landmarks/ に保持しています。
